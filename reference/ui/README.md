# Reference screenshots (research only)

These screenshots of a third-party drawing application were supplied to study workflow, information hierarchy, panel density and tablet ergonomics. They are **not** part of Canvas Forge: they are not packaged, not used as assets, and Canvas Forge does not copy their names, logos, icons, menus, graphics, brush packs or visual identity. See PLAN.md §2 for the functional observations taken from them.
