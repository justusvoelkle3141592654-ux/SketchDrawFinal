# Release notes

## 0.1.0 (first development build, 2026-10-15)

First complete development build of Canvas Forge for Windows 11 (x64, unsigned).

* Workspace: document tabs, grouped command bar with overflow menu, command search (`Ctrl+K`), tool rail with tool groups, contextual tool options, dockable/floating panels (Colour, Palettes, Brushes, Layers, Animation, Reference), Orbit radial menu, size/opacity and navigation pucks, Focus Canvas, compact/roomy density, light/dark theme, left-handed layout, customisable shortcuts.
* Pen input: Pointer Events with coalesced samples, pressure curve editor, tilt, barrel buttons, eraser tip, pen-only mode, touch gestures, diagnostics.
* Engine: sparse tiles, 9 blend modes, groups, clipping, masks, stroke buffer with stabiliser and predictive stroke, symmetry, 37 original brush presets, Brush Lab, brush packs.
* Editing: selections (rectangle, ellipse, lasso, polygon, magic wand), cut/copy/paste, transform with perspective, crop, image/canvas size, rotate/flip, fill, gradient, shapes, raster text, adjustments, guides.
* Files: `.cforge` (atomic save, recovery), PNG/JPEG/WebP import/export, reference images stored in the document.
* Animation: flipbook with exposure, onion skin, held layers, playback, GIF and PNG-sequence export; time-lapse recording with replay and export.
* Not included: PSD/TIFF, video export, code signing.

See PROGRESS.md for verified results and known limitations.
